2. ★ Tendon Transfer의 원칙

이차 운동 예측·활용힘 벡터에 따른 2차 운동을 계획에 반영 — 예: BR을 IOM 배측 경유로 돌리면 pinch와 함께 회내(pronation) 생성

텐션 · 봉합의 현대 개념

  • "과긴장" 도그마 폐기 — Blix curve에 따라 donor 근육의 resting length에서 텐션 설정이 수축력·거리 최대. 간이법: 봉합 전 근육이 스스로 resting tension으로 되감기게 둔다.
  • Coaptation: 전통 Pulvertaft weave(3–4회) → modified side-to-side(1회 weave + side-to-side running locking suture)가 인장강도 더 크고 low-profile → early mobilization 재활 가능.
  • Donor 부족 보완 3종: Arthrodesis Tenodesis Synchronization — 여러 근육의 기능을 "best" 근육 하나로 증류.

보존해야 할 근육 — 함정 포함

  • Wrist extension은 절대 희생 금지. 수의적·충분한 강도의 extensor가 2개 이상일 때만(= ICSHT ≥ 3) ECRL을 donor로 쓴다.
  • Transfer는 ECRL, wrist extension은 ECRB가 담당 — ECRL은 요측 편위 성분이 크고, ECRB가 균형 잡힌 신전.
  • ECRB 강도 판정 함정: 강한 wrist extension만으론 ECRB 강도를 확신 못 한다. grade 5면 가능성 높음 · Bean sign(둘 다 강할 때 근위 전완 ECRL/ECRB 사이 고랑)이 참고 소견.
  • FCR은 저자들도 보존(ICSHT ≥5에서 donor 가능하지만) — 능동 손목 굴곡이 tenodesis release·구축 예방·휠체어 추진·weight shift에 유용.
  • "Functional spasticity"(wrist extension 시 FPL 수축)는 유익 — 건드리지 말 것.

5. 단계 전략 — Two-stage vs Single-stage

Two-stage (3 ≤ IC ≤ 6에서 pinch+grasp 동시 재건)
  • 이유: 수의적 수지 신전 없이 FDP만 구동하면 굴곡 구축이 불가피 + extensor/flexor 재활 프로토콜 상충
  • 간격 2–6개월 · 순서(신전 먼저/굴곡 먼저)는 개별화
  • Extensor phase: EDC·EPL tenodesis 또는 BR→EDC 능동 transfer(IC ≥4) + intrinsic-plasty + 엄지(CMC fusion 또는 opponensplasty 시 APL tenodesis)
  • Flexor phase: ECRL→FDP(synchronization 선행) + PT/BR→FPL + pinch 잔여 요소
Single-stage
  • IC ≥ 6: 신전이 보존/동기화로 해결 — 한 번에, 굴곡 구축 없음, 결과 양호
  • IC 3–5: Friden alphabet procedure (ABCDEFG) — 신전을 extrinsic 대신 intrinsic tenodesis로 해결해 재활 충돌 제거, early rehab 결합
  • Lateral pinch 단독은 원래 단일 단계

Bilateral: 전략 동일 — 한쪽씩 재활 집중 권장, 2단계를 반대쪽 1단계와 병합 가능. 우세손 = opponensplasty(정교함) / 비우세손 = CMC fusion(강도). 감각 없으면 양손 동시 조작 불가함을 상담. IC >3에서도 회복 부담 때문에 pinch만 선택하는 환자가 있다.

6. 술식 상세 (술기 포인트 · 텐션 · 재활)

Posterior deltoid → triceps elbow extension gold standard
  • Posterior 1/3–1/2 deltoid 채취 — 건 길이 부족을 graft로 교량: triceps tendon turn-up flap(저자 선호), TFL, 장족지신건 등 (우열 근거 없음)
  • 저자 술기: triceps 중앙 1/3(≥1 cm)을 원위 부착부에서 분리해 turn-up → Dacron tape 보강 → proximal ulna 4.5 mm 횡터널 통과 crisscross weave → posterior deltoid insertion을 통째로 채취해 graft에 weave
  • 텐션: minimal — elbow 30–40° flexion, shoulder 60–80° flexion에서 고정
  • 특성: workspace 일관 개선, 대개 antigravity 수준. 1년 시점 예측 최대힘의 65% · 신장(stretch)에 특히 취약 → 엄격한 재활 필수
  • 재활: long arm cast(elbow ≤20°) 3–4주 → dial-hinge orthosis 0°에서 시작, 주당 15°씩 flexion 허용(4주에 90°) · 능동 굴곡은 orthosis 한계 초과 금지 10주 · 야간 soft splint 6개월 · 활성화 cue: shoulder 90° abduction에서 horizontal abduction
Biceps → triceps elbow extension 굴곡 구축 동반 시 유리
  • 전제: brachialis 기능 확인 필수(주 굴곡근). deltoid보다 강하거나 대등, 삽입 직접적 — 재활 덜 까다롭고 수술 짧음. non-synergistic → supination 노력으로 활성화 학습
  • 술기: 내측 절개, lacertus fibrosus를 tail로 보존, radial tuberosity에서 분리 → medial routing (ulnar nerve 심부 넓은 터널) → proximal ulna 사선 bone tunnel(6.5 mm, 관절외) 통과, suture를 bone bridge 위 결찰(또는 interference screw), lacertus·triceps split으로 보강
  • 굴곡력 최대 47%↓(불만 없음) · supination 약화는 이점 가능
  • 재활: deltoid와 같은 골격(cast 3–4주 → hinge 주 15°) · gravity-eliminated → 6–8주부터 항중력 · 능동 굴곡 제한 12주 · 활성화 cue: shoulder 90° abduction + forearm supination
  • 파열 최대 14% — early mobilization+저순응·동시수축·fluoroquinolone 연관 → 순수 biceps 발화 학습에 집중
Lateral (key) pinch 재건 — 구성 요소 4가지 BR/PT→FPL 계열

목표 접촉: thumb pulp가 index 중절골 요측(≈DIP 부근). 전제: M3 wrist extension·전완 회내·엄지-수지 관계 양호.

  1. Thumb IP 안정화 — split FPL tenodesis (Mohammed): FPL 요측 반쪽을 부착부에서 분리, 근위로 종분할 → 배측으로 돌려 EPL에 weave. 위치 IP <20° flexion(각도보다 pulp 접촉이 중요) · 경관절 K-wire 3–4주
  2. CMC 처리: ① arthrodesis (C5–C6 최다: palmar abduction 40° · extension 25° · pronation 10°, 교차 K-wire+제3핀 8주) ② House adductor-opponensplasty(IC ≥4): FDS-ring 채취 → hamate hook 경유 → APB에 weave, BR로 구동(wrist 0–20° ext에서 opposition 형성) + 이때 pinch 동력은 PT→FPL ③ 정렬·안정 양호 시 방치
  3. BR→FPL: radial midaxial lazy-S 절개(radial a.·SRN·LABC 보호), BR 광범위 박리(41.7→77.9 mm) → FPL에 modified side-to-side. 텐션: elbow 90° flexion, wrist 0–10° extension에서 pinch가 막 형성 (Murray: elbow 각도-텐션 상호작용) · 변형: IOM 배측 경유로 2차 회내 생성
  4. 술중 수동 평가 + EPL tenodesis: wrist 45° flexion에서 엄지가 neutral plane을 못 넘으면 EPL을 3rd compartment retinaculum에 자기 자신으로 lasso(APL도 동일 기법 가능). index가 pulp와 안 만나면 — FDP tenodesis·lasso·capsulodesis 모두 무효, 표면 보조 사용법 훈련

Passive pinch (IC 0–1, Moberg 원형): 동일 IP·CMC 처리 + BR→ECRB(elbow 90°·wrist 30° ext) + FPL을 radius에 tenodesis. 실제 시행은 드묾(BR 매개 wrist extension이 대개 부족).
재활: 고정 3–4주(강한 weave면 1–2주 후 early motion) → thumb spica · IP핀 4주·CMC핀 8주 제거 · 저항성 pinch는 8–10주까지 금지 · 작은 물체로 잡기 연습(FPL tenodesis 신장 방지).

Palmar grasp — Extensor phase 신전·release 확보
  • Extensor tenodesis (U-plank): retinaculum 근위에서 digital extensor 박리 → radius 배측에 U자형 bone plank를 burr로 조각 → plank 밑으로 건 통과(순서 EDM→EIP→EDC×4, tenotomy 없이) → K-wire 2개로 "close the door"(제거 불필요) · 엄지가 척측 편위로 신전되면 APL tenodesis 추가
  • 능동 신전 transfer (IC ≥4): BR→EDC(±EPL/EIP/EDM) — 포함 근육이 늘수록 효율↓. 건 synchronization(동일 레벨 신전) 후 weave. 텐션: elbow 30–40° flexion·wrist neutral에서 MCP 10–20° extension
  • IC 6: ulnar extensor 건재 → side-to-side synchronization만(저자 선호)
  • Intrinsic-plasty (이 단계에서 선제적):
    • Zancolli FDS lasso — PIP 신전은 되는데 MCP 과신전이 문제일 때: FDS를 chiasm에서 절단, 두 tail을 A1 pulley 근위·장측으로 돌려 자기 봉합. 텐션: wrist neutral에서 MCP flexion·4지 동일 굴곡(cascade 역전)
    • House graft intrinsicplasty — MCP 굴곡 시 PIP lag + Bouvier 음성일 때, index·long에만: PL graft를 index 척측 lateral band → lumbrical canal·intermetacarpal lig. 심부 → long 척측 lateral band에 weave. 텐션: long MCP 40–45° flexion에서 최대 장력 · PIP 신전위 pinning 3–4주
  • 재활: forearm 기반 splint(wrist neutral~약간 신전, intrinsic-plus) → 1–2주에 removable, 점진적 wrist flexion으로 tenodesis glide 형성 · 핀 4주 · full-time splint ~8주 · 야간 splint는 2단계 수술 시까지
Palmar grasp — Flexor phase ECRL→FDP
  • ECRL을 가능한 원위에서 절단(wrist 최대 신전 상태) → FDP 4개를 reverse cascade로 synchronization(wrist ext 시 4지 동일 레벨 굴곡; horizontal mattress 3개) → ECRL을 radial aspect로 volar 우회해 weave
  • 2차 supination 우려 시 pronator quadratus 근위 IOM window로 통과
  • 텐션: wrist 30–45° extension에서 수지 굴곡 형성
  • 수지 신전(자체/tenodesis) 확보가 전제 — 아니면 만기 굴곡 구축
  • 동시에 PT 또는 BR→FPL 등 pinch 잔여 요소 완성
구축·변형 대응 (early procedures) 재건의 전제
  • 수동조작: 어깨·수지 IP에 효과적 — 사전 방사선으로 이소성 골화·잠재 손상·퇴행 배제
  • Elbow: serial casting 우선 — 신전 구축 >100°에서 척골신경 위험 · 실패 시 capsular release (역치: triceps 강하면 50°, triceps 없으면 25°)
  • Intrinsic tightness → 선택적 척측 intrinsic release (grasp 재건 대상자에서 특히)
  • Supination deformity (IC 0–2 호발): botulinum toxin·신전+회내 serial casting → 잔존 시 radial pronation osteotomy(radius midshaft 횡절골, 원위 분절 10–20° 회내, IOM release, plate 양측 6피질 — 학습 재활 불필요, 단일 단계 재건에 병합 적합) · 대안: Zancolli biceps pronator-plasty · 굴곡 변형 동반 시 biceps/brachialis lengthening

  • 시기가 생명: zone of injury 아래(중추성 마비)는 시간 무관 recipient 가능 · zone 내 말초 탈신경은 18–21개월 영구화 window 안에 재신경지배 완료되게 — 신경학적 안정 전 시행이 고려되는 유일한 상황
  • 장점: 완료 시 술후 고정 불필요·치료 강도 낮음 · 단점: 기능 발현까지 6개월–2년, 실패율 10–40% — 실패 인지 시점엔 비가역 (건이전 파열은 revision 가능)
  • Donor morbidity(Fox): deltoid branch 사용 시 abduction −4.5% 수준 · supinator donor는 최종적으로 개선
  • 저자 입장: tendon transfer가 여전히 표준, nerve transfer는 보강(augment) — 향후 고위 손상에서 역할 확대 전망

9. 시기 · 적응 · 금기

급성기~구축 예방 + tenodesis 패턴 보존 (splint·PROM·TES) — C6가 25° elbow 굴곡 구축만으로 C5 수준으로 전락
Complete: 평균 6개월에 수술적 plateau(통념 1년) · incomplete는 1년+ 회복 지속 → 연속 평가로 확인
만성기 = 건이전 표준 시기 · 상한 없음(수상 10년 후에도 동일 성공 — Dunn)
Nerve transfer만 예외적 조기 — 18–21개월 window (§8)
적응
  • 동기(가장 중요)·구체적 목표·시간 투자 의지·지지체계·인지 안정
  • supple joints + donor MMT ≥4
  • (nerve transfer 시) recipient 신경지배 생존 확인 — TENS → 불명확하면 EMG/NCS
금기
  • 현 기능 만족·목표 없음·지지 결여
  • 고착 관절 구축 (선교정 필요)
  • 체간 지지·좌석 부적절
  • 조절 안 되는 spastic 근육은 donor 불가 (단 경도는 가능, functional spasticity는 보존)
  • 말초 탈신경 근육 (모든 재신경화 불가)

개별화: biceps로 휠체어 추진·weight shift 중인 C5 환자 — biceps donor 사용 시 대체 방법 학습을 사전 설명. 소아: SCIWORA 흔함, plateau 빠를 수 있어 조기 수술 가능(Kozin), 작은 건·성장판 고려해 재활 연장.
